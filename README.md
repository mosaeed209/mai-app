# مَعي — installable web app (PWA build)

Generated by `python prototype/build_pwa.py` from `prototype/mai.html`. Do not edit `index.html` by hand.

## Install on iPhone
1. Open the site URL in **Safari** (not Chrome).
2. Tap **Share** → **Add to Home Screen** → **Add**.
3. Launch «مَعي» from the home screen. After the first launch it works offline.

Reminders on iPhone appear as cards inside the app (iOS web apps cannot schedule local notifications; the native TestFlight build in `app-ios/` does that).

## Update
Rebuild the prototype, run `python prototype/build_pwa.py`, commit and push. The service-worker cache version changes automatically; installed apps pick up the new version on their next launch after the previous one.
